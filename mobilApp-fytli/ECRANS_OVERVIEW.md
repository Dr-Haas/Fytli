## 🎨 Légende des symboles

- `(👤)` : Avatar utilisateur
- `(X)` : Avatar ami (lettre initiale)
- `[ Button ]` : Bouton interactif
- `┌─┐` : Carte/conteneur
- `████` : Barre de progression
- `🔥💪✨` : Emojis intégrés
- Dégradé : Fond avec gradient de couleurs Fytli

## 🔄 Navigation entre écrans

```
Splash
  ↓
Login (peut être sauté)
  ↓
Dashboard ←─────────┐
  ├→ Feed           │
  ├→ LockedFeed     │
  ├→ Profile        │
  ├→ FriendProfile  │
  └→ Workout        │
      ↓             │
   SessionSummary   │
      ├→ DailyCard  │
      └─────────────┘
```
