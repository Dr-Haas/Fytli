## 🛠️ Maintenance de la Documentation

### Ajouter un nouveau document
1. Créer le fichier .md
2. L'ajouter dans cet index
3. L'ajouter dans la section appropriée du README.md

### Mettre à jour un document existant
1. Modifier le document
2. Mettre à jour la date de dernière modification en bas du document
3. Si changement majeur, mettre à jour cet index

### Supprimer ou consolider un document
1. Vérifier qu'il n'est pas référencé dans d'autres documents
2. Mettre à jour cet index
3. Ajouter à la section "Fichiers Supprimés" si consolidé
